# Meu Site Pessoal

Este é meu site pessoal desenvolvido com Vite, Tailwind CSS e Supabase.

## Tech Stack
- Vite
- Tailwind CSS
- TypeScript
- Supabase (backend / banco de dados)
- Netlify (deploy)

## Estrutura
- `/src` → código-fonte principal
- `/supabase/migrations` → scripts de banco de dados
- `index.html` → página principal
- `vite.config.ts` → configuração do Vite
- `.env` → variáveis de ambiente (não commitar a real!)
